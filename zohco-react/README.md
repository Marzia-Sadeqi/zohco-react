# Zohco — React + Vite

A React version of the Zohco eco-friendly website. Built with React, Vite and Framer Motion (plain CSS, no Tailwind).

## Run
```
npm install
npm run dev
```
Open http://localhost:5173

## Build
```
npm run build
npm run preview
```

## Structure
- `src/components/` — one file per section: Hero (with navbar), LogoTicker, Values, Solutions (video + accordion), Services, Gallery, AboutMore, Showcase, Stats, Testimonials (slider), Adventure, Blog, Footer
- `src/data/content.js` — all texts, images, testimonials, blog posts and footer links
- `src/index.css` — all styles
- `public/images`, `public/videos` — media files
